# 人物—植物/物体编辑美学

本文件是 `orange-accent-wallpaper-prompts` 的条件式视觉模块。仅在主题同时包含人物与植物、花卉、叶片、枝条、树冠、产品或雕塑，或用户明确提出 `High Fashion Editorial` / `Scale Shift` 时读取。橙色锚点、冷色静区、9:16 安全区和写实摄影仍优先于本模块。

## 1. 两个概念的职责

### High Fashion Editorial

这是艺术指导层，负责造型、姿态、裁切、非对称和视觉态度，不是品牌名称、滤镜或“高级感”形容词。人物姿态和版式必须由动作、偏置、裁切与留白来证明，而不是靠标签。提示词要把风格翻译成可观察的选择：

- 雕塑感剪裁、明确肩线或流动廓形、真实可辨的粗花呢/羊毛/丝绸/棉麻等材质。
- 克制而有意、但不对称的姿态：自然重心偏移、肩胯反向、躯干轻微扭转、左右手动作不等量或偏轴视线；脚底承重、接触阴影和衣物褶皱必须支持动作。
- 杂志级构图只选择一种版式逻辑：偏置主体、边缘裁切、对角视觉路径、前景遮挡或大面积负空间；用一个主体、一个橙色锚点和一块安静背景建立主次，不做居中填满或电商目录。
- 服装与环境形成色彩或形状关系，但不依赖 Logo、商标或品牌符号。
- 摄影应像编辑大片：有明确美术指导和模特动作，而不是电商目录、婚纱照、磨皮美容广告或 CGI 造型渲染。

不要只写 `luxury`、`beautiful`、`fashionable`、`editorial`；必须补充轮廓、材质、一个身体动作证据、一个视线/手部证据、机位和一个版式/裁切证据。

### Scale Shift

这是可选的人物—物体比例错置关系，只在被选中的方向启用。比例异常要服务于主体关系或情绪，不是随机放大道具。编写时至少回答：

1. 谁相对谁变大或变小，比例是轻微错位还是明显错位。
2. 人物与物体在哪里接触、倚靠、坐落或被遮挡，承重和重心是否成立。
3. 透视、景深、投影方向、遮挡边缘和材质反应是否支持这个尺度。
4. 画面中是否还偷偷加入第二个异常；若有，删除它。

若启用 Scale Shift，推荐只选一种机制：异常大型花瓣成为座面、叶片像墙面包围人物、枝条变成桥或栏杆、人物缩小为舞台中的环境尺度。除非用户明确要求，不要同时使用巨物、悬浮、镜像和空间断裂；未启用时不要强行放大或缩小花卉。

## 2. 植物与物体的空间翻译

优先提取颜色、曲线、纹理、方向和节奏，把对象重构为空间构件；只有当字面主体本身是用户重点时，才保留完整的植物形态。

| 原始对象 | 首选空间翻译 | 避免的快捷写法 |
| --- | --- | --- |
| 花朵、花瓣、花簇 | 花瓣座面、花冠舞台、弧形墙、半透明穹顶、层叠色面 | 直接塞进“巨型花朵”，没有接触、支撑和比例说明 |
| 叶片 | 包裹人物的叶片平面、叶脉路径、遮阳 canopy、折叠屏风 | 叶片随机漂浮、叶脉像发光电路 |
| 茎、枝条、藤蔓 | 柱、扶手、桥、门槛、悬挂线性构件 | 多条枝条缠绕人物或形成不可解释的网状物 |
| 树冠、灌木 | 连续背景体块、拱形天幕、远景色墙 | 密集森林和无意义小叶片堆叠 |
| 产品、雕塑、日常物 | 座台、展陈台、单一建筑面、镜头前的尺度参照 | 复数道具、漂浮陈列、品牌 Logo |

翻译后仍须保留原对象的材质证据：花瓣的薄度和脉络、叶片的纤维与反光、枝条的木质纹理、金属或织物的真实粗糙度。

## 3. 人物、姿态与景别

- 默认使用成年人物；年龄、身份和文化特征按用户输入写清，不用含糊的 `young beauty`。
- 中近景可裁到腰部、膝部或大腿，但至少保留一个完整的接触点和部分支撑结构，让尺度关系可读。
- 默认优先非对称但有支撑的动作：放松肩颈、单脚或臀部自然承重、肩胯反向、躯干轻微扭转、手指轻触物体、左右手动作不等量、肘部微弯、下巴和视线有轻微方向性；避免镜像站姿、双手对称、芭蕾式僵硬、过度摆拍和不可能的关节。
- 人物不是装饰贴纸。服装褶皱、皮肤高光、发丝受光和投影方向必须与环境光一致。
- 中近景人物可成为视觉主体，顶部不设固定低信息区；让人物、植物、橙色锚点和背景大形先形成统一版式。只有用户指定锁屏时，才按设备模板避开界面关键区域。

## 4. 橙色与冷色的编排

### 花卉作为橙色主体

将明亮交通橙 `#ff4900` 集中在一簇花瓣、花冠或少量花朵表面，形成单一清晰色块，默认约占画面 `15%-20%`。橙色花面可以承载人物、切入人物侧后方或作为前景遮挡，但不要让橙色碎成许多同等强度小花。用浅蓝、青色或深蓝背景提供至少约 `55%` 的冷色静区。

### 背景作为橙色主体

仅当用户明确要求背景主导时，使用一个哑光、织物、涂层或半透明的橙色结构面，约占 `20%-25%`。它可以是弧形墙、幕布、展台背板或切割平面；不要做成无材质的发光渐变。人物和植物应以中性色或冷色与其分层；只有用户明确指定锁屏模板时，才让对应界面区域保持低对比。

两种情况下都遵循“一个主橙色锚点 + 最多一个低强度反射回声”。回声只能是边缘反光、地面反射或远处很小的同色细节，不得成为第二个视觉中心。

### 单一自然植物场景的橙色载体调整

当画面只包含一株树、花、枝条或其他单一自然植物时，默认不要在植物旁边放置宽大的独立矩形防风布。它会同时引入工业物件、第二视觉重心和不匹配的材质语汇。可从以下三种方向中选择：

1. **植物内生元素（默认优先）**：将橙色放入同一植物的花冠、果实、种荚、嫩叶或一小簇成熟叶片，使其与枝条连接、共享风向和光线，形成约 `15%-20%` 的单一结构面。
2. **自然化薄膜**：把布改写为从枝干节点生长出的窄幅半透明叶鞘、膜状苞片或有机薄片；沿植物的弯曲方向贴合，保留一个明确接触点，不做平直的矩形幕墙。它是可选的轻度超现实关系。
3. **重构防风布**：只有用户希望保留布料概念时使用。将其缩减为随植物倾斜的窄幅布带或局部遮片，固定点、风向、褶皱、遮挡和接触阴影必须清楚；让布与植物共享一条对角或垂直路径，避免独立站立、硬边矩形和第二个同等强度的焦点。

三种方向都应保留一个橙色锚点；禁止“孤立植物 + 宽大直立防风布 + 多个橙色回声”的并置。植物内生元素最自然，薄膜方向最具超现实感，重构防风布最接近原始意图但需要最严格的支撑和尺度控制。

## 5. Prompt 组装顺序

按以下顺序写一条连续的 Midjourney v8.2 英文描述：

1. 成年人物、身份、服装轮廓和摄影类型。
2. 植物/物体的具体形态、空间翻译、人物位置和景别。
3. 若该方向启用 Scale Shift，写明相对比例、接触、支撑、重心、透视和投影；否则，写出所选的悬浮、双层空间、入口或写实关系，不添加比例错置。
4. 主构图系统、非对称裁切、视觉路径、边缘裁切余量；仅在用户指定锁屏时加入顶部与底部界面安全区。
5. 橙色载体、`#ff4900`、面积和冷色静区的角色分工。
6. 光源方向、材质反应、景深、自然高光滚降和有机胶片颗粒。
7. 必要排除项与平台参数，参数统一放在末尾。

不要把 `High Fashion Editorial`、`Scale Shift` 当作孤立标签留在句尾；它们必须在服装、动作、尺度和空间语句中被展开。

## 6. 质量门槛

交付前逐项检查：

- 一秒缩略图能读出人物、一个橙色锚点和主要空间关系；若启用 Scale Shift，还必须读出唯一的比例关系。
- 非对称姿态是否有身体、视线或手部证据；杂志级构图是否能通过偏置、裁切、对角线、遮挡或负空间读出，而非只靠标签。
- 编辑感来自轮廓、材质、姿态和裁切，而非品牌名或泛化形容词。
- 人体、脸、手、关节、服装结构、植物解剖和物体材质没有变形。
- 若人物与花卉/物体接触，接触处存在合理的遮挡、接触阴影或承重关系；若启用 Scale Shift，尺度改变不能破坏透视和景深。
- 橙色没有漂成正红、酒红或霓虹；冷色静区仍是画面主场。
- 没有第二个超现实机制、重复脸、额外人物、随机漂浮物、文字、Logo、水印、塑料皮肤、过度磨皮、商业目录感或 CGI 渲染感。

## 7. 方案差异

同一请求输出多个方向时，至少改变两个结构变量：编辑服装轮廓、非对称姿态证据、杂志版式、植物空间翻译、尺度机制、橙色载体、机位/裁切或光线模式。默认最多一个方向使用 Scale Shift；其他方向使用不同的空间异常或写实关系重构，不靠更换几个形容词制造假差异。
